## The Gap We're Filling

Public vulnerability data is excellent — OSV.dev (Google) and the NVD together cover
npm, PyPI, Maven, Cargo, RubyGems, NuGet, and more. But turning a raw CVE feed into a
decision still requires:

- Knowing which API to call and how to parse it
- Correlating CVEs to the exact packages in *your* project
- Figuring out what the threat actually *does*
- Reading dozens of CVE records by hand

**None of that answers the question a developer has right now:**

> "Are the packages I'm about to add to my project malicious?"

That question has no zero-friction, zero-signup answer today. We built one.

## The Five Things Nobody Else Does

### 1. Zero Setup Scanning — no account, no key
Every dependency-scanning workflow today asks for something first: an account, an API
token, a CI integration, a repo connection.

**We require nothing.** Drag a file in. Results in 15 seconds. Public data only.

---

### 2. Namespace Cluster Detection
Attackers don't publish one malicious package — they publish ten. `aone-kit`,
`aone-kit-cli`, `aone-sandbox`, `aone-utils`... all the same threat actor, same campaign.

Raw CVE feeds evaluate packages in isolation. They'll flag `aone-kit` but won't tell you
the other three in your file are the same coordinated attack.

**We do.** We group flagged packages by name prefix, detect when 2+ share a prefix, and
surface a banner: *"Coordinated namespace attack detected — 3 packages, same threat actor."*

---

### 3. AI Narrative Per Package
Knowing a package is RED is not enough. Developers need to understand *what it does* to
make a decision fast.

Every flagged package gets a 2–3 sentence plain-English explanation generated by Claude:

> *"This package was identified as a dependency confusion attack targeting internal
> packages. It executes a post-install script that sends environment variables to an
> external server. Remove immediately and rotate any secrets exposed in the last 30 days."*

A CVE list shows an ID and a score. We explain the threat.

---

### 4. Chat With Your Results
After the scan, developers can ask questions directly about their specific results:

- *"Which package should I remove first?"*
- *"Is there a safe version of axios I can upgrade to?"*
- *"Which of these RED packages is actually exploitable in my context?"*

The AI answers against their exact scan — not generic documentation.

---

### 5. Layered Public Intelligence (OSV.dev + NVD)
Every package is cross-checked against **OSV.dev**, which aggregates NVD, GitHub Security
Advisories, RustSec, PyPA, and more. On top of that, **NVD** adds a per-package
**trust score** (CVSS severity, CISA KEV / exploit references, recency) and a live
**ecosystem pulse** of newly published CVEs.

**Result:** broad public coverage plus a quality/risk signal — no enterprise catalog needed.

## The Data Behind It

Entirely public, keyless-usable sources:

| Source | What it provides |
|--------|------------------|
| OSV.dev | Per-package CVEs across npm, PyPI, Maven, Cargo, RubyGems, NuGet |
| NVD API 2.0 | New-CVE pulse, trends, CVSS severity, CISA KEV / exploit references |

Plus a bundled local sample catalog for offline/demo flagging of known-malicious packages.

When a package is flagged, we show:
- **CVE count and top CVE** — with CVSS score
- **Trust score (0–100)** — composite from NVD severity, KEV/exploit refs, recency
- **Threat type & attack vector** — from the local malware catalog when matched
- **Spread velocity** — sample spread data in the bundled catalog

## Why It's Viable as a Product

### It Costs Almost Nothing to Run
- One OSV `querybatch` request per scan regardless of file size
- NVD calls capped per scan (default 10) with a rolling rate limiter
- LLM calls only for flagged (non-green) packages
- Narrative caching means repeat threat types reuse the same LLM response
- 161-dependency Maven file scans in ~15 seconds

### It's a Lead Generation Engine
Every scan is a moment of intent. A developer uploads their file, sees 8 RED packages,
and asks "how do I prevent this automatically?" The lead capture form captures them right
then — email + company, one click.

### It's Embeddable Anywhere
Zero-friction widget: *"Scan Your Dependencies — Free."* No signup required until they
want alerts. Converts passive visitors into active leads.
